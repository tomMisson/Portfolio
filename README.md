# 👨‍💻 Tom Misson: Digital Portfolio

### My digital flag in the ground. 🚩✨

This is a high-performance technical showcase built to "Enterprise Grade" standards. It automatically stays up-to-date with your latest achievements, projects, and certifications using a "Zero Maintenance" data architecture.

---

## 🛠️ Why it's cool:
- **Angular + Analog:** Refined with the latest Angular features (Signals, Standalone Components) and file-based routing with SSR/SSG.
- **GSAP Animations:** High-performance, buttery-smooth animations including a custom Euclidean network background and parallax journey timeline.
- **Data-Driven:** Auto-pulls projects from **GitHub API** and loads experience/certs from a local JSON store for maximum performance and SEO.
- **Infrastructure as Code:** Full automation of Cloudflare DNS and Netlify deployment settings via **Terraform**.
- **Mobile First:** Designed from the ground up to provide a premium experience on every device.

---

## 🚀 Tech Stack:
- **Frontend:** [Analog](https://analogjs.org/) (Angular meta-framework)
- **Styling:** Tailwind CSS 4.0
- **Animation:** GSAP (GreenSock) + ScrollTrigger
- **Infrastructure:** Terraform (HCL)
- **DNS/Edge:** Cloudflare

---

## 📂 Project Structure

/web        <-- The Analog (Angular) application
